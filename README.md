# Conch releases

This public repository distributes Conch desktop installers, signed updater packages, per-platform update manifests, and release notes. Application source remains private.

Only tested platform builds are promoted to an update channel. Channels are independent, so an unfinished Windows or Intel build does not block the Apple Silicon build.

Update downloads are verified against the signing public key shipped in Conch. Release packages currently use development code signing; they are not Apple Developer ID notarized builds.
